# Event Booking Project

## Overview
Event Booking Project 90 is a Java-based application designed to facilitate event booking and management. This project provides a comprehensive solution for handling event reservations, bookings, and related operations.

## Getting Started

### Prerequisites
- Java Development Kit (JDK) 8 or higher
- Maven or Gradle (depending on build configuration)
- Git

### Installation
1. Clone the repository:
```bash
git clone https://github.com/janithu-a/Event_Booking_project_90.git
```

2. Navigate to the project directory:
```bash
cd Event_Booking_project_90
```

3. Build the project:
```bash
mvn clean install
# or
gradle build
```

### Running the Application
```bash
mvn spring-boot:run
# or
gradle bootRun
```
